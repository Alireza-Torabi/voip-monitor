# رفع اشکال

**وضعیت:** برنامه هنوز قابل اجرا نیست. موارد زیر فقط برای شالودهٔ مخزن هستند.

- اگر `node`، `npm` یا `docker` پیدا نمی‌شود، ساخت برنامه و بررسی Compose ممکن نیست. نصب ابزارها باید طبق سیاست میزبان انجام شود.
- اگر بررسی شالوده خطا می‌دهد، فایل گزارش‌شده را پیش از ثبت در Git اصلاح کنید.
- اگر فایل خصوصی توسط Git نادیده گرفته نمی‌شود، پیش از نوشتن اطلاعات محلی، `.gitignore` را اصلاح کنید.
- اگر ارسال به GitHub شکست خورد، خطا، نشانی remote و وضعیت احراز هویت را بررسی کنید. اطلاعات ورود را خودکار تغییر ندهید و ارسال اجباری انجام ندهید.
- اگر اطلاعات محرمانه وارد فایل‌های آمادهٔ ثبت یا تاریخچه شد، کار را متوقف کنید، وضعیت انتشار را بررسی کنید و اعتبارنامهٔ آسیب‌دیده را تغییر دهید. حذف در ثبت بعدی تاریخچه را پاک نمی‌کند.

راهنمای اتصال PBX، بازیابی پایگاه داده و داشبورد پس از پیاده‌سازی افزوده می‌شود. تغییر پیکربندی PBX واقعی بدون طرح بررسی‌شده انجام نشود.
