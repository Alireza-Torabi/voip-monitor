# عملیات

**وضعیت:** فقط بررسی‌های شالودهٔ مخزن قابل اجرا هستند. هنوز سرویس پایش برای اجرا، پشتیبان‌گیری یا بازیابی وجود ندارد.

بررسی‌های کنونی را از ریشهٔ مخزن اجرا کنید:

</div>

```sh
python3 scripts/check_foundation.py
git status --short --branch
git check-ignore .local/DEPLOYMENT_CONTEXT.md
```

<div dir="rtl">

این بررسی‌ها وجود فایل‌های عمومی، الگوی محیطی بی‌خطر و نادیده‌گرفتن مسیرهای خصوصی را کنترل می‌کنند. جایگزین بازبینی دستی فایل‌های آمادهٔ ثبت در Git یا ابزار کامل کشف اطلاعات محرمانه نیستند.

در طرح آینده، داده‌ها زیر `/data` و کلید اصلی در `/data/secrets/master.key` خواهند بود. نسخهٔ پشتیبان باید پایگاه داده و کلید را با هم حفظ کند و بازیابی آن آزمایش شود. راهنمای عملیاتی استقرار، سلامت، ارتقا، بازگشت نسخه و حذف نصب پس از ساخت سرویس نوشته خواهد شد.
