# پیکربندی برنامه

**وضعیت:** فاز ۲، کار ۴، تنظیمات اعتبارسنجی‌شده، SQLite و نگهداری رمزگذاری‌شدهٔ اطلاعات محرمانه را فراهم می‌کند. فایل `.env` خودکار بارگذاری نمی‌شود. تنظیمات را از محیط فرایند یا ابزار استقرار بدهید؛ `.env.example` نمونه‌ای عمومی و ثبت‌شده در Git است و فایل واقعی `.env` در Git نادیده گرفته می‌شود.

| تنظیم | پیش‌فرض | کاربرد |
| --- | --- | --- |
| `APP_ENV` | `production` | یکی از `development`، `test` یا `production` |
| `APP_HOST` | `127.0.0.1` | نشانی شنود HTTP |
| `APP_PORT` | `3000` | درگاه HTTP؛ عدد صحیح از ۱ تا ۶۵۵۳۵ |
| `APP_LOG_LEVEL` | `info` | یکی از `debug`، `info`، `warn` یا `error` |
| `DATA_PATH` | `/data` | پوشهٔ مطلق داده‌های برنامه |
| `APP_SECRET_DIR` | `<DATA_PATH>/secrets` | پوشهٔ مطلق کلید اصلی محافظت‌شده |
| `APP_DATABASE_PATH` | `<DATA_PATH>/monitor.sqlite3` | مسیر مطلق پایگاه دادهٔ SQLite |

مسیرها اعتبارسنجی می‌شوند و در پیکربندی نوع‌دار قرار می‌گیرند. هنگام شروع، پوشه و فایل پایگاه داده در صورت نبودن ساخته می‌شوند و مهاجرت‌ها پیش از شنود HTTP اجرا می‌شوند. مقدار صریح نامعتبر، سرور را پیش از آغاز شنود متوقف می‌کند. خطای پیکربندی نام فیلد را نشان می‌دهد، نه مقدار آن را. جزئیات ساختاریافتهٔ گزارش‌ها برای نام فیلدهای دارای `password`، `secret`، `token`، `key` یا `authorization` پوشانده می‌شوند. پاسخ سلامت همچنان فقط `{ "status": "ok" }` است.

تنظیمات محیط برنامه از راه‌اندازی PBX جدا هستند. نشانی‌ها و دیگر فرادادهٔ غیرمحرمانهٔ PBX در راه‌اندازی احرازشدهٔ آینده وارد و هنگام اجرا ذخیره خواهند شد. اطلاعات محرمانهٔ PBX در محل اختصاصی و محافظت‌شده نگهداری خواهند شد، نه در متغیرهای دائمی فرایند مانند `PBX_HOST`، `AMI_USERNAME` یا `AMI_PASSWORD`. اطلاعات خصوصی توسعه و استقرار فقط زیر `.local/` نادیده‌گرفته‌شده قرار می‌گیرند و نباید وارد نمونه‌های ثبت‌شده شوند.

حالت اولیهٔ راه‌اندازی `SETUP_REQUIRED` است؛ `SETUP_IN_PROGRESS` و `COMPLETE` برای مراحل آینده در نظر گرفته شده‌اند. پس از مهاجرت پایگاه داده، برنامه کلید ۳۲‌بایتی را در `<APP_SECRET_DIR>/master.key` می‌سازد یا اعتبارسنجی می‌کند. پوشه باید با مجوز 0700 و فایل کلید با مجوز 0600 در اختیار مالک باشد. اگر رکورد رمزگذاری‌شده وجود داشته باشد، کلید گمشده دوباره ساخته نمی‌شود و برنامه شروع نخواهد شد. هنوز حساب مدیر، رابط راه‌اندازی، AMI، SSH یا اتصال PBX پیاده‌سازی نشده‌اند. مسیر میزبان برای اتصال آیندهٔ `/data` را بهره‌بردار انتخاب می‌کند؛ داده‌های زمان اجرا را در پوشهٔ کد قرار ندهید. [معماری](ARCHITECTURE.md) را ببینید.
