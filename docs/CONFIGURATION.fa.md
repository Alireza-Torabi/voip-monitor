# طرح پیکربندی

**وضعیت:** فقط نشانی و درگاه شنود سرور توسعه از متغیرهای محیطی خوانده می‌شوند؛ بارگذار پیکربندی PBX و رابط راه‌اندازی اولیه هنوز وجود ندارند.

فایل `.env.example` فقط پیش‌فرض‌های عمومی دارد. فایل واقعی `.env` در Git نادیده گرفته می‌شود. نشانی PBX، درگاه‌ها، اطلاعات AMI و SSH، منطقهٔ زمانی و مسیرهای ذخیره‌سازی هنگام راه‌اندازی در برنامه وارد خواهند شد؛ ویرایش کد یا ساخت دوبارهٔ تصویر لازم نخواهد بود.

در روند پیشنهادی، نخست مدیر محلی ساخته می‌شود. سپس مدیر، پروفایل Asterisk/FreePBX را وارد می‌کند، اتصال فقط‌خواندنی AMI را می‌آزماید، در صورت نیاز SSH محدود را آزمایش می‌کند، نتیجهٔ کشف و قابلیت‌های ناموجود را می‌بیند و پس از تأیید پایش را آغاز می‌کند.

فرادادهٔ غیرمحرمانه در SQLite و اطلاعات محرمانه به‌صورت رمزگذاری‌شده نگهداری خواهد شد. کلید اصلی بیرون از Git قرار می‌گیرد. رابط کاربری نباید اطلاعات محرمانهٔ ذخیره‌شده را دریافت کند. دادهٔ ناموجود نباید به‌صورت صفر نمایش داده شود. جزئیات در [معماری](ARCHITECTURE.md) آمده است.

سرور توسعه متغیرهای `APP_HOST` و `APP_PORT` را می‌پذیرد و به‌صورت پیش‌فرض فقط روی رابط محلی و درگاه 3000 گوش می‌دهد. فایل `.env.example` خودکار بارگذاری نمی‌شود.
