# سکوی پایش VoIP (در مرحلهٔ طراحی)

این پروژهٔ عمومی با مجوز Apache-2.0 برای پایش سامانه‌های VoIP/PBX روی سروری جداگانه طراحی شده است. پشتیبانی اولیهٔ برنامه‌ریزی‌شده برای Asterisk و سامانه‌های مبتنی بر FreePBX است. سازگاری با Asterisk 13.x باید بررسی و آزمایش شود. هنوز برنامهٔ قابل اجرا وجود ندارد و اتصال به PBX واقعی انجام نشده است.

[English](README.md) · [معماری](docs/ARCHITECTURE.md) · [وضعیت نصب](docs/INSTALL.fa.md) · [برنامهٔ پروژه](docs/MASTER_PLAN.md)

اطلاعات ویژهٔ هر استقرار و گذرواژه‌ها باید هنگام راه‌اندازی وارد شوند. این چارچوب برنامه‌ریزی برای پایش PBX آماده نیست.
